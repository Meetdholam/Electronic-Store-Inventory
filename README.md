# 🛒 Electronic Store Inventory Management System

A modern, easy-to-use inventory management system for electronics stores built with Python, CustomTkinter, and MongoDB.

## 👨‍💻 Author
**Meet Dholam**
- GitHub: [@Meetdholam](https://github.com/Meetdholam)

## ✨ Features

- ✅ **Add Products** - Add new products to inventory
- ✅ **Update Products** - Modify existing product details  
- ✅ **Delete Products** - Remove products from inventory
- ✅ **Search Products** - Find products by ID or Name
- ✅ **View All Products** - Display all products in a table
- ✅ **Modern GUI** - Clean, dark-themed interface
- ✅ **MongoDB Integration** - Persistent data storage
- ✅ **Tabbed Interface** - Organized layout for better UX
