# 🛒 Electronic Store Inventory Management System

A modern **Electronic Store Inventory Management System** built with **Python, CustomTkinter, and MongoDB**.

The application provides a graphical interface to manage electronic products and perform basic inventory operations such as adding, updating, deleting, searching, and viewing products.

---

## 📌 Project Overview

This project is a desktop-based Electronic Store Inventory Management System designed to make product inventory management simple and easy.

The application connects to a **MongoDB database** for persistent data storage. The graphical user interface is created using **CustomTkinter** and provides an organized tabbed layout for better user experience.

---

## ✨ Features

* ➕ Add new products to inventory
* ✏️ Update existing product details
* 🗑️ Delete products from inventory
* 🔍 Search products by ID or Name
* 📋 Display all products in a table
* 🎨 Modern dark-themed graphical interface
* 🗄️ Store inventory data in MongoDB
* 📑 Tabbed interface for organized management
* 📊 View and manage product inventory easily

## 🗄️ Database

The project uses **MongoDB** for persistent inventory data storage.

The application connects to MongoDB through the Python MongoDB driver **PyMongo**.

MongoDB should be installed and running before starting the application.

## ⚙️ Requirements

Make sure you have installed:

* Python 3.8 or higher
* MongoDB
* PyMongo
* CustomTkinter

Install the required Python libraries using:

```bash
pip install -r requirements.txt
```

---

## 🚀 How to Run

### 1. Start MongoDB

Make sure your MongoDB server is installed and running.

### 2. Clone the Repository

```bash
git clone https://github.com/Meetdholam/electronic-store-inventory.git
```

### 3. Open the Project

```bash
cd electronic-store-inventory
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
python "Electronic Store Inventory Management.py"
```
